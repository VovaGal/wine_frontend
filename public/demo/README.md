# Локальные вина для просмотра интерфейса

`wines.json` содержит первые три записи из предоставленного `wines_metadata.json`, приведённые к формату карточки frontend. Он загружается только при `VITE_DEMO_MODE=true`. Значения `rating` и `roskachestvo` оставлены пустыми, поскольку оценок для этих записей в исходных полях не было.

| Запись | Файл |
| --- | --- |
| Прибой Марченко белое полусухое | `wine_1.webp` |
| Прибой Марченко розовое полусухое | `wine_2.webp` |
| Прибой Марченко красное полусухое | `wine_3.webp` |
| Возможно вы имели ввиду одно из этих вин | `wine_4.webp` |
| Форма для ненайденного вина | `wine_5.webp` |
| Фиолетовый Ранний петнат, учавствует в фестивале вин | `wine_6.webp` |


Можно использовать JPG/PNG и изменить соответствующий `image_url` в `wines.json` (например, `/demo/wine_1.jpg`). Vite раздаёт файлы из `public` по пути `/demo/...`;

Откройте DevTools > мобильный режим. Запуск: `npm install`, скопировать `.env.example` в `.env`, установить `VITE_DEMO_MODE=true`, затем `npm run dev`.
